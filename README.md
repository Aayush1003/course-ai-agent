# Course AI Agent

A lightweight AI-style course recommendation app designed for students who want to find the best courses for their exam goals.

## What it does

- Lets users select their target exam, budget, study pace, and learning style.
- Evaluates a curated course list using a simple scoring model.
- Recommends the best-fit programs with a match percentage, format, duration, and tags.

## Run locally

From the repository root:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files

- `index.html` — landing page and UI shell
- `styles.css` — visual styling and responsive layout
- `app.js` — course catalog and recommendation logic

## Project idea

This repo is a simple demonstration of an AI agent for course discovery. It is intentionally lightweight and works with no install steps, so it can be opened and tested quickly.
